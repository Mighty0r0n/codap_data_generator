# Hinweise zu den verwendeten Datensätzen

Dieses Projekt enthält keine eigenen oder proprietären Datensätze.  
Alle Daten werden über öffentliche Schnittstellen oder Downloadportale bezogen
und unterliegen den jeweiligen Nutzungsbedingungen der Datenanbieter.

## Quellen

- **DWD Climate Data (Deutscher Wetterdienst)**
  - Quelle: https://opendata.dwd.de/
  - Lizenz: Datenlizenz Deutschland – Namensnennung – Version 2.0  
    (https://www.govdata.de/dl-de/by-2-0)

- **GBIF Occurrence Data**
  - Quelle: https://www.gbif.org/
  - Lizenz: Creative Commons Attribution 4.0 International (CC BY 4.0)

- **ReSurveyGermany**
  - Quelle: https://www.bfn.de/themen/monitoring/resurvey-germany
  - Lizenz: gemäß Angaben des Bundesamts für Naturschutz (BfN)

## Nutzungshinweise

Die Skripte in diesem Repository dienen ausschließlich dazu,
diese öffentlichen Daten automatisiert herunterzuladen, zusammenzuführen
und für Bildungs- oder Forschungszwecke aufzubereiten.

Die Rechte an den Daten verbleiben bei den jeweiligen Datenanbietern.
Bitte beachte die jeweiligen Lizenzbedingungen, wenn die Daten weiterverwendet werden.
